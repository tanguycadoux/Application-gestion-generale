Aide sur la syntaxe de recherche

Tous les mots sont requis ; casse et accents sont ignorés.

banc thermique
les deux mots, dans le texte ou les titres
"résistance thermique"
la phrase exacte
therm*
les mots qui commencent par « therm »
-brouillon
sans ce mot (-"cette phrase" marche aussi)
projet:Alpha
dans ce projet ; entre guillemets s'il a des espaces : projet:"Mon projet"
chemin:Réunion/Préparation
sous ce chemin (niveaux séparés par « / »), niveaux dessous compris
tag:urgent
avec ce tag ; plusieurs tag: sont tous exigés
-tag:fini, -projet:Perso
sans ce tag, hors de ce projet (aussi -chemin:)
date:2026-10
les notes d'un mois ; aussi date:2026 ou date:2026-10-15
date:2026-09..2026-10
une plage, bornes comprises ; date:2026-09-15.. et date:..2026 laissent une borne ouverte

Plusieurs projet: ou chemin: se cumulent (l'un ou l'autre).
